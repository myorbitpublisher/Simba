# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private reporting instead:
**Security tab → Report a vulnerability** on this repository.

Include what you found, how to reproduce it, and which Simba version you tested.
You will get a reply as soon as possible, and a fix will be released through Simba's normal automatic update.

## Supported versions

Only the latest release is supported. Simba updates itself from GitHub Releases, so keep automatic updates on.

## What Simba stores

Simba keeps its data on your own computer only (see the data folder in Settings → About). Saved passwords are encrypted with
your operating system's key store. Nothing is sent to a Simba server.
