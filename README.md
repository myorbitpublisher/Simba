# Simba

A personal web browser.

**Windows:** download **Simba-Setup.exe** from the [latest release](https://github.com/myorbitpublisher/Simba/releases/latest) and run it.
Mac and Linux files are on the same page. Installed copies update themselves.

This repository only publishes the installers. Report problems in [Issues](https://github.com/myorbitpublisher/Simba/issues).
